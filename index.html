🔗 从飞书导入数据

获取 Tenant Access Token：
1. 打开 飞书开放平台 → 开发者后台 (open.feishu.cn)
2. 创建企业自建应用 → 获取 App ID 和 App Secret
3. 为应用添加权限：云表格 → 查看电子表格
4. 用 App ID 和 App Secret 调用接口获取令牌：
POST /open-apis/auth/v3/tenant_access_token/internal

注意：浏览器直接调用飞书 API 可能被 CORS 策略拦截。如遇错误请改用「复制粘贴」或「AI助手导入」。
  1. 打开飞书表格 — 在浏览器中打开你的飞书电子表格
  2. 选中数据 — 点击左上角全选按钮，或拖选需要的数据区域
  3. 复制 — 按 Ctrl+C（Mac: Cmd+C）
  4. 粘贴 — 点击下方文本框，按 Ctrl+V（Mac: Cmd+V）
